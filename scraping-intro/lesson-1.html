Syntax reference

soup.select_one('tag')         # first matching element, or None
element.get_text(strip=True)  # the text inside an element
print(value)                  # show it in the output

Python loads when you run the code.

Your output will appear here.
Hint: the heading selector

The visible name is the page’s only h1, so soup.select_one('h1') is enough. You don’t need the class for this page.

Hint: element to text

heading is a BeautifulSoup element. heading.get_text(strip=True) returns just the text inside it, without the tags or extra whitespace.

See a worked solution
import requests
from bs4 import BeautifulSoup

detail_url = BASE_URL + 'practice/frog-rana-temporaria.html'
response = requests.get(detail_url, timeout=10)
response.raise_for_status()
soup = BeautifulSoup(response.text, 'html.parser')

print(response.text[response.text.find('<main'):response.text.find('<main') + 700])

heading = soup.select_one('h1')
name = heading.get_text(strip=True)

print(heading)
print(name)
