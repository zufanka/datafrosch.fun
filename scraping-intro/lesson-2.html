Scoped selectors

The video selects departments and finds commissioners; we select frogs and find families. The HTML differs, so derive your selector from the practice page rather than copying the video’s tree traversal.

5–10 minutes · browser inspector, no Python yet

  1. Open the first listing page ↗. Right-click Common frog’s name and choose Inspect.
  2. Identify the link: its tag, its class, and the attribute that holds the destination. An a is a tag, not a class.
  3. Look at the element around the link. Then inspect a second card and check that the same structure repeats.
  4. Focus the Elements or Inspector panel. Press Ctrl+F (Cmd+F on Mac) and search for a[href]: all links with destinations. Then use the class you found to select only frog links.
  5. Confirm you highlighted ten a elements, not ten cards. Use the same selector in soup.select().

Selector reference: tag.class means a tag with that class. .class tag means a tag inside that class. Avoid copied full paths and nth-child.

Inspector search can also match text, so use a class or attribute selector rather than a bare a. These observation answers are not saved.

Hint: a selector for the ten links

The wanted links are anchors with the class frog-link: a.frog-link. On page 1 that matches ten elements. .frog-card a.frog-link narrows it further by saying “inside a frog card”, which is useful when a page has other links with the same class.

Hint: why the bare tag is too broad

soup.select('a') returns every anchor on the page. Count them, then inspect the first one. A count alone does not tell you what you selected.

Element, href and relative URLs

Excerpt from the edited recording · about 15:24–18:48

Stops at 18:48. Then inspect the family and try the code. Watch on YouTube ↗ from 15:24; pause at 18:48.

This clip resumes a failed request: it received a whole link element instead of a URL. We’ll read href and use urljoin to build the URL, rather than joining strings as in the video.

A selected link is not a URL. It is an element that contains text and attributes. Read the destination with get('href'). The listing’s href is relative — frog-rana-temporaria.html — so resolve it against the listing URL before making another request.

Then inspect Common frog’s detail page. Find the family value, Ranidae. Note its tag and class, and compare it with the scientific name Rana temporaria just below the heading. The family sits in a definition list, not in the heading.

Hint: the ten frog links

Use the anchors inside the cards: soup.select('.frog-card a.frog-link'). soup.select('a.frog-link') also matches the ten links here; the scoped version makes the parent–child relationship explicit.

Hint: text versus href

link.get_text(strip=True) gives Common frog. link.get('href') gives frog-rana-temporaria.html. Printing the whole link shows the element with both.

Hint: the family selector

The family is a dd element with the class frog-family: detail_soup.select_one('.frog-family'). Selecting h1 returns the frog’s name instead.

See a worked solution
import requests
from bs4 import BeautifulSoup
from urllib.parse import urljoin

listing_url = BASE_URL + 'practice/frogs-1.html'
response = requests.get(listing_url, timeout=10)
response.raise_for_status()
soup = BeautifulSoup(response.text, 'html.parser')

links = soup.select('.frog-card a.frog-link')

link = links[0]

frog = link.get_text(strip=True)
href = link.get('href')

print(len(links))
print(links[0])
print(frog)
print(href)

detail_url = urljoin(listing_url, href)
detail_response = requests.get(detail_url, timeout=10)
detail_response.raise_for_status()
detail_soup = BeautifulSoup(detail_response.text, 'html.parser')

family_element = detail_soup.select_one('.frog-family')
family = family_element.get_text(strip=True)

print(detail_url)
print(family)
