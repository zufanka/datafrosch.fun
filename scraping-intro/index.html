What we’ll do

Collect the name, family and source URL for ten frogs on one listing page. In each lesson, inspect the page, write Python, then compare the result with the source.

Before you start

Use desktop Chrome or Firefox with an internet connection. You’ll inspect a practice page in another tab. Basic Python helps; setup code, syntax references and hints are supplied.

Run Python here

Use the code box in each lesson. The first run downloads Python from jsDelivr; your code runs in your browser against the practice pages. Code and progress are saved in this browser only.

Inspect → write → compare

Watch a short clip, inspect the practice page, then try the code. Hints and solutions stay closed until you need them. Finish with two questions. There’s no passing score.

Check your output against the page, even if you use AI for help. A passing code check cannot tell whether you understand the selector.

About the video and practice pages

The recording uses Commission departments and commissioners; we practise with frogs and families. Notes explain the differences between clips and exercises.

Frog facts come from Wikipedia and photos from Wikimedia Commons, with credits on each detail page. Exercises fetch only the practice HTML. YouTube connects only when you load a clip and may use cookies or other storage.
